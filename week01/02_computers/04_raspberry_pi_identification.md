## Reflection
Why are many components integrated into a single board in embedded computers such as the Raspberry Pi?
Write **100 words**. 
Raspberry Pi intergrates many components onto a single board,making it a compact and versatile computer. The SoC acts as the brain, handling calculations and control tasks,while the GPIO pins let users connect external devices and sensors. USB ports supports peripherals like keyboards and mice, and HDMI provides display output. The power input supplies energy to the whole system, and the microSD card stores the operating system and flies. Network and wireless features add connectivity. Combining all these parts in one small board makes the Raspberry Pi useful for learning, projects,and embedded computing applications.
